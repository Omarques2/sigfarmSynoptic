# SVG Synoptic Map Sample

This folder contains certification sample artifacts for marketplace submission.

Files:
- `SVGSynopticMapSample.pbix`: final validated sample report for submission
- `municipios_por_estado/`: SVG source files used by the report and drill maps

Important:
- final validated `.pbix` is the submission artifact
- sample PBIX must use same production package version as submitted `.pbiviz`
- sample must work offline
- semantic model inside final sample must not depend on machine-specific absolute paths

Validation checklist:
- Validate visuals, drill, editor, guide and Hints & Tips page
- Confirm sample uses submitted production `.pbiviz`
- Confirm export and offline opening still work

Recommended final PBIX filename:
- `SVGSynopticMapSample.pbix`
