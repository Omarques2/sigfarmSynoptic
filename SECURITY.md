# Security Policy

## Supported Versions

Security fixes are applied to the latest maintained code on the repository default branch.

## Reporting a Vulnerability

If you discover a security issue, please report it privately:
- Email: contato@sigfarmintelligence.com
- Subject: `Security report - Sigfarm Geosynoptic`

Please include:
- A clear description of the issue
- Reproduction steps
- Potential impact
- Proof of concept (if available)

Do not open public issues for undisclosed vulnerabilities.

## Response Process

- Acknowledgment target: within 5 business days
- Initial triage and severity assessment
- Fix planning and release timeline based on impact
