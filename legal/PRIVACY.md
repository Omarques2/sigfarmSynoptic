# Privacy Policy - Sigfarm Geosynoptic

Last updated: 2025-01-12

This Privacy Policy describes how Sigfarm Intelligence ("Controller") handles personal data when you use the Sigfarm Geosynoptic Power BI visual ("Software").

## 1. Scope
This policy applies to use of the Software within Power BI. It does not apply to other products or services from the Controller unless stated.

## 2. Data collected
Describe any data collected (if applicable):
- Report data: The visual requires report data to function. It depends on importing an SVG and table fields that map SVG IDs to plot values on the panel.
- Telemetry/diagnostics: No telemetry is collected.
- Device/environment data: No device data is collected.

## 3. How we use data
We use data to:
- provide and improve the Software;
- provide technical support and diagnostics;
- comply with legal obligations.

## 4. Data sharing
We share data with:
- service providers: None;
- authorities: when required by law.

## 5. Storage and retention
Data stays local in the report; the visual does not store data.

## 6. International transfers
Not applicable.

## 7. Security
