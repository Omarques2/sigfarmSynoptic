# Privacy Policy - SVG Synoptic Map

Last updated: 2025-01-12

This Privacy Policy describes how Sigfarm Intelligence ("Controller") handles personal data when you use the SVG Synoptic Map Power BI visual ("Software").

## 1. Scope
This policy applies to use of the Software within Power BI. It does not apply to other products or services from the Controller unless stated.

## 2. Data collected
The visual processes report data locally inside Power BI to render SVG map areas, labels, legend, drill state, and tooltips.

The visual does not:
- send report data to external services;
- collect telemetry;
- load external web resources to function.

The visual may store small local UI preferences by using Power BI host `storageService`, such as:
- dismissed help/tutorial state;
- dismissed sanitization warning signature;
- last processed SVG signature.

These local values do not include report dataset values.

## 3. How we use data
We use report data only to render the visual inside Power BI and to support interactions requested by the user.

## 4. Data sharing
We do not share report data with third-party service providers. Disclosure occurs only if required by law.

## 5. Storage and retention
Report data stays local in the Power BI environment. Local UI preferences may be stored through Power BI host local storage only.

## 6. International transfers
Not applicable.

## 7. Security
We take reasonable measures to protect data, including SVG sanitization, no external resource access, and no telemetry collection.

## 8. Data subject rights
You may request access, correction, deletion, portability, and information about processing, as required by applicable law.
To exercise rights, contact contato@sigfarmintelligence.com.

## 9. Children's data
The Software is not intended for users under 13 years old.

## 10. Changes to this policy
We may update this policy periodically. The "Last updated" date indicates the current version.

## 11. Contact
For privacy questions, contact contato@sigfarmintelligence.com.
